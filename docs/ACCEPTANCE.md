# 真机验收清单

跑一遍大约 10 分钟。每项都写了「怎么测 / 期望什么 / 挂了先看哪里」。

准备：服务已启动（默认 `:1101`），LX Music 已导入 `http://<地址>:1101/api/v0/lx-script.js`。

---

## 0. 启动自检

```sh
curl -s http://127.0.0.1:1101/api/v0/ping            # 期望 {"code":0,"data":"pong"}
curl -s http://127.0.0.1:1101/api/v1/status          # 期望含 configVersion / cache.hits
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:1101/   # 期望 200（自检页）
```

- [ ] 三个都符合
- [ ] 启动日志里有 `已注册解析源 codes=[kg kw mg mock tx wy]` 和 `缓存已就绪`

挂了先看：端口被占 / `-conf` 目录不可写 / `CacheDir` 权限。

---

## 1. 五个源：搜索 → 播放

对 `kw / kg / mg / wy / tx` 各做一次：

- [ ] LX 里搜一首**免费歌**，结果能出来
- [ ] 点播放，**能出声**（不是转圈、不是 0:00 卡住）
- [ ] 拖动进度条能跳

命令行对应检查：

```sh
curl -s 'http://127.0.0.1:1101/api/v1/search?pt=kw&q=%E6%B5%B7%E9%98%94%E5%A4%A9%E7%A9%BA&sz=3'
curl -s 'http://127.0.0.1:1101/api/v0/url/kw/<上一步的 id>/128k' | head -c 200
```

- 期望：`{"code":0,"data":"http://..."}`，把 `data` 丢浏览器能下载
- 若回 `{"code":2,...}`：按 `msg` 里的原因处理（见第 6 节）

  - 不允许：报 24bit 但实际是 mp3
- [ ] 咪咕：`128k`/`320k` 能放；`flac24bit`（ZQ）没有登录态时应明确报「没有权限/未提供」

## 4. 切后台 / 长时间播放

- [ ] 放歌 → 切到桌面 30 秒 → 回 LX：仍是播放态、进度连续
- [ ] 连续播放 30 分钟：内存无明显增长（`adb shell dumpsys meminfo` 或系统设置里看）

## 5. 缓存与直链过期

```sh
# 第一次（回源）与第二次（命中缓存）耗时应当有差别
time curl -s 'http://127.0.0.1:1101/api/v0/url/kw/<id>/128k' >/dev/null
time curl -s 'http://127.0.0.1:1101/api/v0/url/kw/<id>/128k' >/dev/null
curl -s 'http://127.0.0.1:1101/api/v1/status' | grep -o '"hits":[0-9]*'
```

- [ ] `hits` 会增长
- [ ] 放一首放着不动 **超过 30 分钟**，再点同一首：仍能播（说明过期直链被作废重取了，不是发死链）

## 6. 配置真生效（热更）

改 `data/dynamic.toml`，**不重启**，等 2 秒：

- [ ] `[Srcs.Kw] Enable = false` → `curl /api/v0/url/kw/<id>/128k` 回 **503「已停用」**
- [ ] 改回来 → 立刻恢复
- [ ] `[Auth.ApiPass] Enable = true, Value = 'k'` → 不带 key 请求回 **401**；带 `?key=k` 通过
- [ ] `[Apis.ApiOnly] = true` → `curl /` 回 **404**

---

## 7. 失败排查表

| 现象 | 先看 | 常见原因 |
|---|---|---|
| 搜索空 | `curl /api/v1/search?...` 的 `msg` | 上游改版；看日志里 `kg:/mg:/wy:` 前缀 |
| 取链 `code:2` | `msg` 里的根因 | 免费档没了 / 该曲需要会员 / 上游限流 |
| 歌词对不上 | 请求的 id 是否来自同一源 | 跨源混用 id（每个源 id 语义不同） |
| 播放 10 秒断 | 直链是否带 `expi` | 上游把直链有效期调短了；缓存会在过期后自动重取 |
| 内存涨 | `cache` 命中率 | 缓存目录写不进去（只看日志 `缓存回填失败`） |

日志里全部带源前缀（`kw:` `kg:` `mg:` `wy:` `qq:`），直接 `grep` 前缀就能定位。

## 8. 回归红线

- [ ] **绝不谎报音质**：响应里的 `qual` 必须等于实际文件档位
- [ ] **取链失败不静默**：要么 JSON 错误带原因，要么（配了 `ErrMp3` 时）302 到错误音频
- [ ] **停用的源不回落**：不能悄悄换源给结果
- [ ] **缓存不返回死链**：超过 `expi` 的直链必须重新取
